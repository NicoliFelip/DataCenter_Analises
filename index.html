Matriz de disponibilidade dos dados

Como ler: correlação visual não implica causalidade. As bases possuem anos, escalas geográficas, metodologias e unidades diferentes. O objetivo deste painel é identificar padrões comparáveis e pontos que merecem investigação, não atribuir causalidade apenas pela associação entre séries.
Relacionamentos utilizados: país, cidade, estado/região e ano são chaves de ligação quando estão disponíveis. Quando a combinação exata não existe, o painel preserva a granularidade original em vez de fabricar uma correspondência.
Projeto de análise comparativa ambiental de data centers. Dados originais preservados nas bases do repositório. Dashboard desenvolvido em HTML, CSS e JavaScript, com Plotly e SheetJS para visualização e leitura das planilhas.

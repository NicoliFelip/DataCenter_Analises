Como as relações foram construídas: a chave geográfica mais confiável entre as bases é o país. Data centers têm cidade/estado/endereço/coordenadas, enquanto as bases nacionais de água usam país. O Aqueduct 4.0 também possui estado/província, mas a correspondência com o campo State dos data centers só é feita quando os nomes coincidem após normalização. Não é criada uma relação cidade ↔ indicador hídrico quando a base hídrica não possui cidade.

Nota metodológica: os indicadores de água não medem o consumo de água dos data centers. Eles descrevem condições e pressões hídricas em escalas nacional/subnacional. A associação com data centers é espacial/descritiva. Diferenças entre versões do Aqueduct não devem ser interpretadas como uma série temporal única sem considerar suas metodologias e períodos de referência.
